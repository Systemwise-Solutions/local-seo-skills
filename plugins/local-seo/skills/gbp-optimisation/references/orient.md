# Orient: what the profile job needs, and where to find it

Find each piece yourself first. Ask the user only for what you can't find, in one message, and say why you need it. If a brief exists, confirm it in one line and ask only about gaps.

| The job needs | Look here first | Why it matters |
|---|---|---|
| The profile | A Maps link in the brief or conversation, a connected tool, a search for the business name | Everything is measured against what the profile says now. |
| The name on the signage | The website footer, logo, legal or company registration page, invoices or photos the user shares | The profile name must match it. Anything added is a suspension risk and the first change. |
| Customers come to it, or it goes to them | Whether the profile shows an address, site copy ("we come to you", "visit us"), opening hours for a door | Decides address visibility, the service area and which photos make sense. |
| The searches that bring revenue (up to 5), and which pays most | Service pages, Search Console queries, the profile's search terms, the brief | The primary category follows the work that pays most, and each money search needs a service named for it. |
| Where customers come from | Site copy, location pages, the current service area, the brief | Sets where you check who is winning. |
| How a customer becomes revenue | Booking widget, quote form, phone-first site, online ordering, menu | Decides which link matters and what the baseline counts. |
| Rules on what it can say | A regulator, professional body or brand guidelines named on the site; claims the site already avoids | Shapes descriptions, services, products and posts. Find the rule before writing. |
| One location or many; people, departments or brands under one roof | Location pages, store finder, team pages, Maps search of the address | Decides whether to fix per estate or per place, and whether extra listings are legitimate. |
| Profile access | The user | Manager access is enough to make changes. The owner account should stay with the business. |
| What's been changed before | `local-seo-log.md`, the user ("a past agency optimised it") | Past keyword stuffing, moves and rebrands explain most odd fields, and you shouldn't undo deliberate choices blind. |
| Anything that changes the order | The user | A suspension, a recent move or rebrand, a new phone number, a deadline. |

Ask for screenshots of the edit screens when no tool can read the profile: the owner's view is the only free source for the business's own secondary categories, services and attributes.

## The brief

Write or update `local-seo-brief.md` with what you learned, in plain labelled lines, under 40 lines. For this job, make sure it holds: the signage name, whether customers visit, profile access, the competitors to beat, and any rule on what the business can say. Other skills read it, so keep it factual.

## Many locations

For more than a handful of locations, work on a sample (strongest, weakest, typical), then group changes by cause across the rest. Say plainly that checking every branch's competitors needs a scanning tool.
